About Me

Hi, I'm Nur Tarikul Islam. I built this Tri-Vector Security Scanner as my final year project to explore how cybersecurity, machine learning and automation can work together to protect everyday users.

What I wanted to learn

I wanted to go beyond theory and build something that actually runs: train a model on real phishing data, wrap it in a web app, and connect it to outside services such as the Have I Been Pwned database. This project is where those pieces came together.

Tools I used

  • Python
  • Flask
  • scikit-learn
  • Random Forest
  • OpenCV
  • Pillow
  • zxcvbn
  • HTML / CSS
  • JavaScript

What I built

URL Scanner

A machine learning model that rates a link as phishing or safe.

Quishing Detector

Reads a QR code from an image and checks the link inside it.

Password Checker

Scores password strength and checks it against known breaches.
