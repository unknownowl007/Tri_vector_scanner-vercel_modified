Limitations

No detector is perfect. Knowing where this one can be wrong helps you use it sensibly.

URL Scanner

Looks at text only

It judges the shape of the link, not the page behind it. It never opens the site or checks what it contains.

New attacks can slip through

A brand-new phishing site with a clean-looking link can be marked safe. Safe legitimate links with odd structure can be flagged by mistake.

Depends on its training data

The model is only as good as the examples it learned from, and phishing styles change over time.

Quishing Detector

Needs a clear image

Blurry, cropped, tilted or low-contrast photos may not decode.

Only links are checked

If a QR code contains plain text, a contact card or Wi-Fi details, there is no link to scan.

Password Checker

Needs internet access

The breach lookup calls an outside service. If it is unreachable, the result shows no leaks even though none were actually checked.

"Not found" is not "safe"

A password missing from known breaches can still be weak or guessable.

Use this tool as a second opinion. When a link or message feels wrong, go to the official website directly instead of clicking.
