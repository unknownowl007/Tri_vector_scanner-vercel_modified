Limitations

No detector is perfect. Knowing where this one can be wrong helps you use it sensibly.

URL Scanner and Enhanced URL

Looks at text only

It judges the shape of the link, not the page behind it. It never opens the site or checks what it contains.

About 86% accurate

On the test set the model was right about 86% of the time. Roughly one link in seven can be judged wrongly.

New attacks can slip through

A brand-new phishing site with a short, clean-looking link can be marked "not detected". Safe links with odd structure can be flagged by mistake.

The confidence is not a probability

A score of 80% does not mean 80% of such links are phishing. Treat it as a rough signal, not a guarantee.

Known-link list is historical

A match in the local list comes from an old dataset, not a live reputation check. A link missing from the list is not proven safe.

Depends on its training data

The model learned from one public dataset. Phishing styles change over time, so accuracy falls unless it is retrained.

Quishing Detector

Needs a clear image

Blurry, cropped, tilted or low-contrast photos may not decode. You must upload a picture; there is no live camera scanning.

Only links are meaningful

If a QR code contains plain text, a contact card or Wi-Fi details, there is no link to scan, yet the text is still passed to the classifier.

Password Checker

Needs internet access

The breach lookup calls an outside service. If it cannot be reached, the page says the breach check is unavailable, and the strength rating is still shown.

"Not found" is not "safe"

A password missing from known breaches can still be weak or guessable.

Do not enter a password you use

The password is sent to this application before it is checked. Use a throw-away example instead.

Domain Tools

Depend on outside services

Certificate, registration, redirect and IP lookups rely on DNS, registries and third parties that can be slow, unavailable, or hide data.

Lookalike list is short

Only ten brands are compared. Names joined with hyphens, such as paypa1-secure-login, and digit-for-letter swaps inside longer names can be missed.

A valid certificate is not proof

Many phishing sites also have valid HTTPS certificates. A redirect chain or registration date is a clue, not a verdict.

Redirect check is limited

It follows at most 8 redirects, reads only the response headers, and only supports standard web ports. It cannot see redirects done by scripts inside a page.

IP location is approximate

The country and city come from a free service and can be wrong. The lookup works only for public addresses.

Speed Test

One quick measurement

It uses a single download and upload against one Cloudflare server, so results vary from run to run.

The project itself

A prototype

It has no rate limit, user accounts or request-size policy, so it is not ready for heavy public use without more safeguards.

History stays in your browser

Scan history is saved only on your own device, limited to the last 50 checks, and is lost if you clear your browser data.

Use this tool as a second opinion. When a link or message feels wrong, go to the official website directly instead of clicking.
