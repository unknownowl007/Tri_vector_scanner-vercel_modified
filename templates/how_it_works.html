How This Works

The app has three tools. Each one sends your input to the Flask server, which analyses it and returns a result.

1. URL Scanner

  1. You enter a link. The browser sends it to the server.
  2. Features are extracted. The server turns the text of the link into 15 numbers, described below.
  3. The model decides. A trained Random Forest classifier votes across 300 decision trees and returns phishing or safe, with a confidence score.

The 15 features

  • Total length, number of dots, hyphens, slashes and subdomains
  • Presence of @, ?, underscores and percent signs
  • A second // inside the link, or an IP address instead of a domain name
  • Whether the link uses HTTPS, and the share of characters that are digits
  • Words like login, verify, secure or bank
  • Well-known brand names such as Google, PayPal or Microsoft
  • Endings like .php, .html, .aspx or .exe

2. Quishing Detector

  1. You upload an image containing a QR code.
  2. OpenCV reads the code and extracts the link stored inside it.
  3. The same classifier runs on that link, so QR codes get the same protection as typed links.

3. Password Security

  1. Strength is scored with zxcvbn, which looks for common words, patterns and keyboard runs rather than just counting characters.
  2. The breach check is private. Your password is hashed with SHA-1, and only the first 5 characters of the hash are sent to Have I Been Pwned. The full password never leaves the server.
  3. You get advice. The result shows a rating, a breach count, and suggestions for improving it.

Behind the scenes

The model was trained on a labelled dataset of phishing and legitimate links, then saved with joblib. The Flask server loads it once at startup, so each scan takes a fraction of a second.
