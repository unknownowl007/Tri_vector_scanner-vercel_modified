How This Works

The app has six tools. Each one sends your input to the Flask server, which analyses it and returns a result. The one exception is the speed test, which runs between your browser and Cloudflare.

1. URL Scanner

  1. You enter a link. The browser sends it to the server.
  2. Features are extracted. The server turns the text of the link into 35 numbers, described below.
  3. The model decides. A trained Random Forest classifier votes across 300 decision trees and returns "phishing detected" or "model did not detect phishing", with a confidence score.
  4. The result is explained. The five signals that moved the score most are listed, each marked as raising or lowering the phishing score. You can download the result as a JSON report.
  5. Extra context is shown. If the link also appears in the project's local list of known phishing links, that is shown as background only. The model decides the verdict.

The 35 features

  • Size: length of the whole link, host name, path and query
  • Punctuation: dots, hyphens, @, ?, =, &, colons, underscores, encoded characters and slashes in the path
  • Host: number of subdomains, an IP address instead of a name, an unusual port, user details before the host, an international (punycode) name, and risky endings such as .top or .tk
  • Characters: share of digits, longest run of digits, and how random the host name and link look (entropy)
  • Words: words like login, verify, secure or bank, well-known brand names in the host, and link shorteners such as bit.ly
  • Path and file: path depth, number of query parameters, fragments, a double slash in the path, and risky endings like .php, .html, .exe or .zip

2. Quishing Detector

  1. You upload an image containing a QR code.
  2. OpenCV reads the code and extracts the link stored inside it.
  3. The same classifier runs on that link, so QR codes get the same checks as typed links.

3. Password Security

  1. Strength is scored from 0 to 4 with zxcvbn, which looks for common words, patterns and keyboard runs rather than just counting characters.
  2. The breach check is private. The password is hashed with SHA-1, and only the first 5 characters of the hash are sent to Have I Been Pwned. The password itself is never sent to that service.
  3. You get advice. The result shows a warning, suggestions and the number of times the password appears in known breaches.

4. Enhanced URL

  1. You enter a link in the Enhanced URL tab.
  2. The 35-signal model runs on it, using the same features as above.
  3. You see the verdict, the confidence, the number of signals analysed, the strongest signals, and a JSON report you can download.

5. Domain Tools

  1. Validate SSL. The server connects to the site's secure port and reports whether its certificate is valid, who issued it, and when it expires.
  2. WHOIS / RDAP. The server looks up public registration details, such as the registrar and the dates, through the RDAP registry service.
  3. Analyze redirect chain. From the URL Scanner tab, the server follows up to 8 redirects and lists each step, so you can see where a short link really goes.
  4. Check lookalike domain. The domain is compared with ten well-known brands to catch tricks like paypa1.com.
  5. IP lookup. You can enter a public IP address to see its approximate location and network details. The address is sent to ipwho.is.

These tools only contact public internet addresses. Private and local addresses are refused, so the tool cannot be used to probe internal networks.

6. Speed Test

  1. Your browser downloads 10 MB of test data from Cloudflare and times it.
  2. Your browser uploads 5 MB and times that too.
  3. The result is shown in Mbps. It measures your own connection, not the connection to this site.

Scan history

The last 50 successful checks (URL, enhanced, QR, redirect, lookalike, SSL, WHOIS and IP lookups) are saved only in your own browser, so you can review them on the Scan History page. The server keeps no record, and you can clear the history at any time.

Behind the scenes

The model was trained on a labelled dataset of phishing and legitimate links, then saved with joblib. The Flask server loads it once when it starts, so each scan takes a fraction of a second. The app runs on Vercel and is published from its GitHub repository.
